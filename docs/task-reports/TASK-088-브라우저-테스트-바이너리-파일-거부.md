# TASK-088: 브라우저 테스트 — 바이너리 파일 거부

## 상태
완료

## 날짜
2026-11-17

## 작업 요약
바이너리 파일을 올리면 서버가 거부하고 화면에 오류 메시지와 해결 방법이 표시되는지 확인했다.

## 변경 파일
- `frontend/e2e/tasks.spec.ts` (T088 시나리오)

## TDD 결과
- 검증 항목: PNG 시그니처를 가진 바이트를 `fake.py`라는 이름으로 업로드 → 대화상자 안 경고에 "바이너리 파일은 업로드할 수 없습니다."와 "소스 코드 텍스트 파일만 지원합니다…"(서버가 준 `suggestion`)가 함께 표시 → 대화상자가 열린 채 유지 → DB에 Task가 0개.
- 결과: 통과.

## 기술 결정
- 일부러 **확장자는 정상(`.py`)이고 내용만 바이너리**인 파일을 썼다. 브라우저는 확장자와 크기만 알 수 있어 이 파일을 통과시키므로, 서버의 내용 검사가 동작하는지를 실제로 확인할 수 있다.
- 서버 오류의 `message`와 `suggestion`이 둘 다 화면에 나오는지 확인한다(프론트엔드가 `suggestion`을 버리지 않는다는 점).

## 비고
- 이 테스트의 앞 단계 작업(통합 확인)에서 이미 한 번, 서버 오류가 화면에 남은 채 다른 검증 오류가 겹쳐 보이는 문제를 찾아 고쳤다(TASK-081 비고 참고). 그 회귀는 단위 테스트가 지킨다.
