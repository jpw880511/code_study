# TASK-087: 브라우저 테스트 — 11MB 파일 거부

## 상태
완료

## 날짜
2026-11-17

## 작업 요약
11MB 파일을 올리면 오류 메시지와 함께 거부되는지, 그리고 아무것도 만들어지지 않는지 확인했다. 브라우저의 즉시 검사와 서버의 최종 거부를 둘 다 확인했다.

## 변경 파일
- `frontend/e2e/tasks.spec.ts` (T087 시나리오)

## TDD 결과
- 브라우저: 11MB(`big.py`)를 선택하면 전송 전에 즉시 "파일 크기가 10MB를 초과합니다."가 표시되고, "Task 만들기"를 눌러도 대화상자가 열린 채 유지되며 DB에 Task가 0개.
- 서버: 브라우저 검사를 건너뛰는 클라이언트를 가정해 같은 파일을 API로 직접 보내면 `413 file_too_large`, 메시지 "파일 크기가 10MB를 초과합니다.", `details.max_size_mb = 10`. 이때도 Task는 0개.
- 결과: 통과.

## 기술 결정
- 서버 검증은 브라우저 컨텍스트의 `page.request`로 보낸다. 쿠키는 포트와 무관하게 `localhost`에 붙으므로 로그인 상태가 그대로 쓰인다.
- "거부"를 메시지가 아니라 **DB에 아무것도 남지 않았음**으로도 확인한다(검증 실패가 부분 저장을 남기지 않는다는 계약).

## 비고
- 11MB는 정확히 한도를 넘는 값이 아니라 여유를 둔 값이다. 경계(10MB 정확히 / +1바이트)는 단위 테스트가 고정한다.
