## 기술 결정
- 붙여넣기는 파일 이름이 없으므로 서버가 `pasted_code<확장자>` 파일을 만들고 확장자는 고른 언어에서 정한다(계약 문서).

## 비고
- **"언어 감지" 해석**: 작업 설명은 "verify language detection"이지만, 붙여넣기에서는 서버가 내용을 보고 언어를 감지하지 않는다. 사용자가 드롭다운으로 고른 언어를 그대로 쓴다(FR-013). 이는 Pygments의 내용 추측이 틀린 이름을 저장하는 문제(T065 실험: JS 코드를 GDScript로 판정)를 피하려는 의도적 설계다. 그래서 이 테스트는 "감지"가 아니라 "고른 언어가 올바른 이름으로 저장되고 표시되는지"를 확인한다. 실제 감지(확장자 기반)는 T084(`main.py` → python), T085(폴더 → javascript)에서 간접 확인되고, 단위 테스트가 12개 확장자를 모두 검증한다.
- 언어 미선택 시 오류 문구는 단위 테스트와 실제 HTTP 검증에서 확인했다. 이 스펙에는 넣지 않았다.
