## 작업 요약
`CodePanel`이 업로드한 코드 파일을 보여 줍니다.

- 파일이 1개면 파일 이름만 보이고, 여러 개면 `role="tablist"`(이름 "코드 파일")의 탭으로 보입니다. 탭 이름은 `file_path ?? file_name`입니다.
- 선택한 파일의 코드를 `CodeEditor`로 보여 줍니다(언어는 서버가 감지한 `language`, 접근 가능한 이름은 "{파일} 코드").
- 강조 요청 `{file, start, end, nonce}`를 받으면 그 파일로 **먼저 바꾼 뒤** 강조합니다. 파일 이름은 경로 또는 이름으로 맞춥니다(`src/lib/document-files.ts`의 `fileMatches`). 목록에 없는 파일이면 무시합니다.
- 보이는 첫 줄이 바뀌면 `onTopLineChange(파일, 줄)`로 알립니다. 사용자가 탭으로 파일을 바꾸면 그 파일의 1줄을 알립니다(설명 패널이 바뀐 파일을 따라가게).
- 코드가 없으면 "표시할 코드가 없습니다."

## 기술 결정
- 강조 요청이 오면 렌더링 중에 상태를 조정합니다("이전 요청과 다르면 파일 전환"). effect를 쓰면 새 줄이 잠깐 엉뚱한 파일에 강조될 수 있어서입니다. 사용자가 탭을 바꾼 뒤에는 같은 요청이 다시 파일을 되돌리지 않습니다(요청이 바뀔 때만 반응).
- 파일 식별은 `id`(서버가 준 값)로 하고, 설명 쪽 이름 매칭에만 경로/이름을 씁니다.
