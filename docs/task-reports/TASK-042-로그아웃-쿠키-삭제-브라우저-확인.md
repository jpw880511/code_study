## TDD 결과

- 확인 결과

  - 서버가 `Set-Cookie`로 두 쿠키를 같은 경로(`/`, `/api/v1/auth`)로 `Max-Age=0` 삭제하는 것을 실서버 HTTP 호출로도 확인
