## 작업 요약
`TaskDetail`의 "문서" 탭 자리표시자를 `DocumentViewer`로 바꿨습니다(`taskId={task.id}`). 연습문제/Q&A 탭은 기존 자리표시자 그대로입니다. 문서 탭이 열려 있을 때만 페이지를 넓게(`max-w-7xl`) 쓰고, 다른 탭에서는 기존 `max-w-3xl`입니다. 이를 위해 `Tabs`를 제어형(`value`/`onValueChange`)으로 바꿨습니다. 문서 탭이 기본이라 처음에는 넓게 보입니다. Radix `TabsContent`는 비활성 탭을 언마운트하므로 다른 탭으로 가면 폴링이 멈추고 돌아오면 다시 시작합니다.
